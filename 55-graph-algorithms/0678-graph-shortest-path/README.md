# 0678 — Shortest path route

Java's `JGraphT` library builds the weighted undirected graph G and computes the unique weighted shortest path from `a` to `e` with `DijkstraShortestPath`. The resulting node sequence is joined with `-` to give the route `a-b-c-d-e` (total weight `4`).

## Run

    jbang GraphShortestPath.java
