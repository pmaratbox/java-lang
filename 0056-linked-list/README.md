# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. A nested `Node` class holds `value` and a `next` reference (null at the tail); the list is a chain of objects that the garbage collector reclaims. (`java.util.LinkedList` is the ready-made version.)

## Run

    javac LinkedList.java && java LinkedList
