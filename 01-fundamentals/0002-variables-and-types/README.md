# 0002 — Variables & basic types

Declare locals of Java's four basic types: `int`, `double`, `String`, and
`boolean` (`String` is the only reference type of the four; the rest are
primitives). The file name must match the public class name. The `+`
operator on strings auto-converts the right operand via `toString` /
autoboxing.

## Run

    javac Variables.java && java Variables
