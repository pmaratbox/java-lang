# 0001 — Hello, world!

The minimal Java program: a compact source file with an instance `void main()`
method that prints via `IO.println`. Java supplies the enclosing class, so the
example needs no explicit class declaration or unused argument parameter.
This syntax requires Java 25 or later and is supported by the repository's JDK 26.

## Run

    javac HelloWorld.java && java HelloWorld

Or launch the source directly:

    java HelloWorld.java
