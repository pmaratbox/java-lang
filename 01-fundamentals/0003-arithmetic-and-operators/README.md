# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). Java's `/` between two `int`s truncates toward zero;
use `(double) a / b` for the fractional quotient. The parentheses around
`(a + b)` are required — `+` is left-associative, so without them the
string-concatenation `+` would consume `a` before the arithmetic happened.

## Run

    javac Arithmetic.java && java Arithmetic
