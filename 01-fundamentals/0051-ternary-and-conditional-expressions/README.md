# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Java's `?:` conditional operator selects between two values of a common type. The `if` form is a statement and cannot be used where a value is needed.

## Run

    javac Ternary.java && java Ternary
