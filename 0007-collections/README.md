# 0007 — Collections

Build an array of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. `int[]` is a primitive array, and `length` is a field
(no parentheses) — unlike `String.length()`. The richer, growable alternative
is `java.util.List` (`List.of(1, 2, 3, 4, 5)`), accessed via `.size()` /
`.get(i)`.

## Run

    javac Collections.java && java Collections
