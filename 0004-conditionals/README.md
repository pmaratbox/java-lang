# 0004 — Conditionals

Compare `n` against 10 and print whether it's less, equal, or greater.
Java's `==` on `int` compares values (primitive), but on reference types it
compares identities — use `.equals()` for value comparison on objects. Edit
`n` to `10` or `15` to exercise the other branches.

## Run

    javac Conditionals.java && java Conditionals
