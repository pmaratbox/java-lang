# 0037 — Operator Overloading

Define how `+` (or an `add` method) combines two points, then add `(1, 2)` and `(3, 4)` and print `(4, 6)`. Java has no operator overloading at all (only the built-in `+` on numbers and strings); a named `add` method is the convention. The record gives `Point` its fields and accessors.

## Run

    javac OperatorOverloading.java && java OperatorOverloading
