# 0604 — Unordered list

Uses Java's real Markdown library — [commonmark-java](https://github.com/commonmark/commonmark-java)
(`org.commonmark`) — to render the fixed Markdown `- a\n- b`. `Parser.parse` builds
the document node, `HtmlRenderer.render` produces the `<ul>`/`<li>` HTML for the
unordered (bullet) list, and the trailing newline appended by the renderer is
stripped with `replaceAll("\n+$", "")`, printing the list HTML — generated by the
library, never hardcoded.

## Run

    jbang MdList.java
