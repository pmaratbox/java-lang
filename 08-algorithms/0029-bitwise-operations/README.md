# 0029 — Bitwise Operations

Compute bitwise AND, OR, and XOR on `6` and `3`, plus a left shift of `6` by one bit, printing `and: 2`, `or: 7`, `xor: 5`, and `shift: 12`. Java's bitwise operators are `&`, `|`, `^`, and `<<`, plus `>>` (arithmetic) and `>>>` (logical, zero-filling) right shifts. They work on `int`/`long`; `6 << 1` doubles to 12.

## Run

    javac Bitwise.java && java Bitwise
