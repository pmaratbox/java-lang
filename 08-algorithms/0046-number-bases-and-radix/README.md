# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `Integer.toHexString`, `toOctalString`, and `toBinaryString` render an `int` in each base with no prefix. `Integer.toString(n, radix)` is the general form for any base.

## Run

    javac NumberBases.java && java NumberBases
