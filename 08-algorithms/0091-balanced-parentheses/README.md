# 0091 — Balanced Parentheses

Using a stack, check whether `(())` is balanced and whether `(()` is balanced, printing `yes` then `no`. `ArrayDeque` is the recommended stack; `push` on `(` and `pop` on `)`, with an empty stack at the end meaning balanced.

## Run

    javac BalancedParens.java && java BalancedParens
