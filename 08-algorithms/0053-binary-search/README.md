# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. Integer division truncates the midpoint. `java.util.Arrays.binarySearch` is the library version, returning a negative insertion point when the key is absent.

## Run

    javac BinarySearch.java && java BinarySearch
