# 0075 — Anagram Check

Check whether each pair is an anagram by comparing sorted letters — `listen`/`silent` and `hello`/`world` — printing `listen/silent: yes` and `hello/world: no`. `Arrays.sort` orders each `char[]`; `Arrays.equals` then compares the sorted arrays for the anagram test.

## Run

    javac Anagram.java && java Anagram
