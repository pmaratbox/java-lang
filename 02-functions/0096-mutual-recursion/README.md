# 0096 — Mutual Recursion

Using two mutually recursive functions `isEven` and `isOdd` (each calling the other), report whether `4` and `3` are even, printing `even` and `odd`. Methods in a class are all visible to one another, so order does not matter for the mutual calls.

## Run

    javac MutualRecursion.java && java MutualRecursion
