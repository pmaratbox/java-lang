# 0006 — Functions

Define `add(a, b)` returning their sum, call it with `3` and `4`, and print
the result. In Java, functions are **methods** that live inside a class; a compact
source file supplies that class implicitly. The instance `void main()` calls
the `static` helper `add` directly. Parameter and return types remain explicit:
`var` is for local variables, not method signatures.

## Run

    javac Functions.java && java Functions
