# 0050 — Stacks

Push `1`, `2`, and `3` onto a stack, then pop them all off and print them in last-in-first-out order: `3 2 1`. `ArrayDeque` is the preferred stack: `push` adds to the head and `pop` removes from it, giving LIFO. The legacy synchronized `Stack` class is discouraged.

## Run

    javac Stacks.java && java Stacks
