# 0553 — Vector sum

Uses the [EJML](https://ejml.org) numeric library's `SimpleMatrix` to build the
row vector `[1, 2, 3, 4]` and reduce it with the library's `elementSum`
operation, which adds every entry together. The resulting total is rounded to an
integer and printed as `10`.

## Run

    jbang VectorSum.java
