# 0052 — Queues

Enqueue `1`, `2`, and `3` into a queue, then dequeue them all and print them in first-in-first-out order: `1 2 3`. `ArrayDeque` is the recommended `Queue`: `add`/`offer` enqueue and `poll()` dequeues (returning `null` when empty). `LinkedList` also implements `Queue`.

## Run

    javac Queues.java && java Queues
