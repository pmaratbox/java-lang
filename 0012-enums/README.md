# 0012 — Enums

Define a `Color` enum (`RED`, `GREEN`, `BLUE`) and print the position of `GREEN`
(1) and `BLUE` (2). A Java `enum` is a full type whose members are singleton
objects; `.ordinal()` returns the zero-based declaration position. (Java enums
can also carry fields and methods.)

## Run

    javac Enums.java && java Enums
