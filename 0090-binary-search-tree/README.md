# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. A nested `Node` class links the tree; `insert` recurses by comparison and the in-order traversal collects the values in sorted order.

## Run

    javac BinarySearchTree.java && java BinarySearchTree
