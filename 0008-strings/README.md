# 0008 — Strings

Given `name = "world"`, print a greeting, the name in uppercase, and its
length. `String` is immutable, so `.toUpperCase()` returns a new string. `+`
concatenates (calling `toString` on non-string operands). `.length()` is a
method returning the number of UTF-16 `char` units.

## Run

    javac Strings.java && java Strings
